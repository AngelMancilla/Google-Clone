# Google Clone

A simple Google homepage clone built with HTML, CSS, and vanilla JavaScript. This project replicates the look and functionality of Google's search interface.

## Features

- **Responsive Search Interface**: Clean and minimalist design matching Google's homepage
- **Functional Search**: Redirects to actual Google search results
- **I'm Feeling Lucky**: Implements Google's "I'm Feeling Lucky" functionality
- **Keyboard Support**: Press Enter to search directly from the input field
- **Material Icons**: Uses Google's Material Symbols for search and microphone icons
- **Custom Styling**: Roboto font family for authentic Google look

## Prerequisites

No dependencies required! This is a vanilla JavaScript project that runs directly in the browser.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AngelMancilla/Google-Clone
   cd GoogleClone
   ```

2. Open `index.html` in your web browser:
   ```bash
   open index.html
   ```
   Or simply double-click the `index.html` file.

## Usage

1. **Search**: Type your query in the search box and either:
   - Click the "Search with Google" button
   - Press Enter on your keyboard

2. **I'm Feeling Lucky**: Type a query and click "I'm Feeling Lucky" to go directly to the first search result

## Technical Details

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Custom styling with Google Fonts (Roboto)
- **Vanilla JavaScript**: No frameworks or libraries
- **Google Material Symbols**: Icon set for search and microphone icons

## Styling

The project uses:
- Roboto font family (400 and 700 weights)
- Material Symbols Outlined icon set
- Custom CSS for Google-like appearance
